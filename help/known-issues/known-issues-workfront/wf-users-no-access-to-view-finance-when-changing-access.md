# Users: Cannot update user access

>[!NOTE]
>
>This issue has been closed because it is working as designed.

When a user attempts to update another user's access from View to Manage on a project, the user cannot update the access, and they see the following message:

"You do not have sufficient access to view finance for this project."

_First reported on December 11, 2025._
